# Form Master — Android MVP

Includes bilingual UI, on-device photo resize, PDF merge/split, and a general document checklist. The current PDF "compress" function re-saves a PDF and does **not** guarantee smaller output; replace with a proper optimizer before advertising compression.

## Build a test APK
1. Extract ZIP on a computer with Android Studio and Android SDK installed.
2. Open this folder in Android Studio and let Gradle sync.
3. Use **Build > Build APK(s)**.
4. APK should appear at `app/build/outputs/apk/debug/app-debug.apk`.

This project has not been compiled/tested in this environment. Do not upload to production until all functions are tested on multiple devices and release build is signed.
